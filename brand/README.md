# Saucepot brand kit (from the app repo)

- colors.json: the app's semantic colour tokens, light and dark (src/theme/tokens.ts). Generate CSS variables from this file; add no new colours.
- fonts/: Nunito static files (Regular 400, SemiBold 600, Bold 700, ExtraBold 800, Black 900) + OFL.txt licence. Self-host with next/font/local.
- stew/: Stew the mascot, idle / happy / roast, 200×200 viewBox, flat colours. Same drawing as the app and the app icon.
- app-icon.png: 1024 iOS light icon (favicon, apple-touch-icon, OG image source).
- Spacing scale (pt → px): 4, 6, 8, 10, 12, 14, 16, 20 (gutter), 24, 32, 48. Radius: 10, 12, 14, 16, 18, 20, 22 (cards), 28, pill.
- Type: display 34/40 Black, title 28/34 Black, headline 20/25 Black, body 17/24 SemiBold, label 15 ExtraBold, caption 13 Bold.
